# v1.27.0：CPR 3.52.1 适配与暂停账户跳过检测

同步 CPR 3.52.1 SDK、官方打包器及 UI 组件库 0.12.0；订阅名称沿用宿主显示值，并同步 Business、Enterprise 和科研套餐的备用名称及长标签换行。

额度暂停或手动暂停的账户在「最新检测结果」显示「已暂停调度」，禁用检测及选择。判断仅读取宿主账户状态，不发送模型检测请求；旧报告和历史色块保持原样。手动提交、自动定时、日志触发都会拦截暂停账户，已排队任务在每次请求前复查，暂停时终止为无分数的「已暂停调度」，不增加新的请求次数。

账户状态每 30 秒复查，也可手动刷新；恢复后可以重新提交检测。额度耗尽和限流仍沿用各自原有规则。

宿主范围：`>=3.52.1,<3.53.0`。发布者 `sirly`，作者 `Sirly`；插件 ID 保持 `sirly.modeltrace-health`，可更新同 ID 的现有实例，保留配置、计划和历史。旧 `personal` 版仍需另行安装并导入配置。

Linux x86_64、glibc 2.36+ 测试包：`sirly.modeltrace-health-1.27.0-x86_64-unknown-linux-gnu.tar.gz`，附带 SHA-256 文件。纯 Rust 引擎，不包含 Python/NumPy。ARM64 本地未构建，未公开发布。

SDK 与打包器提交：`1173f6263da46fabab4715f774d00ceac38e15d3`。ModelTrace 指纹库提交仍为 `6cd4a8ff0f3f4e49d6d6969dd2fbadfa1569fde2`，18 个模型。
