# v1.26.1：测试包版本更新

版本统一升级为 1.26.1，包含 1.26.0 测试包中的纯 Rust 评分、质量分数历史及与主项目一致的订阅显示。账户列表的「历史记录」与「最新检测结果」、检测历史的「质量分数」与「最高候选」均以独立列展示。

状态：本地测试包，已由 [1.27.0](v1.27.0.md) 接续，未公开发布。宿主范围：`>=3.50.0,<3.51.0`；Linux x86_64 / ARM64（aarch64），glibc 2.36+。本地已提供 x86_64 测试包，ARM64 尚待构建验证。

发布者为 `sirly`，作者为 `Sirly`，插件 ID 保持 `sirly.modeltrace-health`。可从同 ID 的 1.26.0 测试包更新现有实例；旧 `personal.modeltrace-health` 仍需安装新插件并导入配置，其历史及在线指纹库不会自动迁移。

Linux x86_64 包名：`sirly.modeltrace-health-1.26.1-x86_64-unknown-linux-gnu.tar.gz`，附带 `.sha256` 校验文件。

完整功能说明见 [1.26.0](v1.26.0.md)，本版构建与升级检查见[验证记录](../verification-v1.26.1.md)。
